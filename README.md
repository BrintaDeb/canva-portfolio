A modern, responsive, and interactive clone of the Canva portfolio for **Brinta Deb** — Graphics & Web Designer based in Kolkata.

## ✨ Features

- **Exact Visual Fidelity**: 13 presentation slides mapped to a 1366x768 reference canvas with responsive scaling and authentic typography (`Arsenica`, `Mansalva`, `TT Commons Pro`, and `Arimo`).
- **Interactive Day & Night Toggle**: Slide 6 features a fully functional Day/Night toggle widget that flips between Sun & Moon and switches the whole portfolio between Light and Dark mode.
- **Interactive Project Modals**:
  - **Netflix Clone ("Believer 2")**: Modal with live playback simulation trigger.
  - **World Mark Foundation (Wix & Webflow)**: Comprehensive impact and portal case studies.
  - **Interactive Instagram Carousel**: Swipeable/clickable slider with SEO strategy tips.
  - **Anti-Ragging Tour & Holi Festival 2021**: Detailed campaign showcases.
  - **Canva Embedded Projects (Slide 8)**: Interactive cards that open full project previews.
- **Playable Video Reels**: HTML5 vertical video players for **Route Finder Tours Bali**, **Our Brews**, and **Nagpal Di Hatti** with audio toggles.
- **Artwork Lightbox**: Clickable Demon Slayer anime sketches (Tanjiro, Zenitsu, Inosuke) with zoom-and-pan full-screen lightbox.
- **Direct Contact Triggers**:
  - Direct WhatsApp chat link
  - One-click copy for email (`brintadeb15@gmail.com`) and phone (`+917005581453`) with instant toast alerts
  - Direct Message modal form with email drafting and clipboard copy actions
- **Dual Viewing Experience**: Switch seamlessly between **Slide Deck Presentation Mode** (with arrow key navigation) and **Continuous Scroll Mode**.

## 🚀 Getting Started

No build step or external dependencies required! Just open `index.html` in any browser or launch a local web server:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js / npx
npx serve .
```

Open `http://localhost:8080` in your web browser.
